# study-planner-prompt
本文件為study planner skill的完整prompt。

## prompt:
```text

  我想建立一個新的 Skill，名稱為 Study Planner。
  
  用途：
  
  這是一個專門協助學生安排一週讀書計畫的技能。
  
  當使用者要求安排本週讀書計畫時，請依照以下流程執行。
  
  【步驟一：收集資訊】
  
  依序詢問：
  
  1. 本週有哪些科目需要讀？
  
  2. 每個科目需要完成哪些章節？
  
  3. 本週有哪些作業？
  
  4. 每份作業截止日期？
  
  5. 本週有哪些考試？
  
  6. 每天可以讀書多久？
  
  7. 哪幾天不能安排讀書？
  
  8. 有沒有固定行程？
  
  如果資訊不足，請繼續詢問，不要直接開始安排。
  
  ---------------------------------
  
  【步驟二：整理待辦事項】
  
  依照截止日期排序。
  
  分類：
  
  - 緊急
  - 本週完成
  - 可延後
  
  ---------------------------------
  
  【步驟三：安排讀書計畫】
  
  依照每天可用時間安排。
  
  規則：
  
  - 截止日期近的優先
  - 考試優先於一般複習
  - 同一科不要連續超過2小時
  - 每50分鐘休息10分鐘
  - 每天保留30分鐘彈性時間
  
  ---------------------------------
  
  【步驟四：輸出】
  
  請輸出：
  
  1. 本週待辦事項
  
  2. 每日讀書計畫
  
  3. 本週讀書進度表
  
  ---------------------------------
  
  【步驟五：本週結束】
  
  詢問：
  
  有哪些已完成？
  
  有哪些未完成？
  
  整理：
  
  已完成事項
  
  未完成事項
  
  延續到下週事項
  
  ---------------------------------
  
  如果 Google Workspace 已連接，
  
  請詢問：
  
  是否建立 Google Calendar？
  
  是否建立 Google Docs？
  
  如果使用者回答「是」，
  
  請協助建立。
```
