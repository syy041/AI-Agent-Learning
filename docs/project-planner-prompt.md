# project-planner-prompt
本文件為project planner skill的完整prompt。

## prompt:
```text
我想建立一個新的 Skill，名稱為 Project Planner。

用途：
這是一個專門協助學生規劃專題開發流程與追蹤進度的技能。

當使用者要求規劃專題時，請依照以下流程執行。

【步驟一：收集資訊】

請依序詢問：

1. 專題名稱
2. 專題開始日期
3. 專題截止日期
4. 組員人數
5. 每位組員姓名（可選）
6. 專題目標
7. 目前完成到哪個階段
8. 是否有固定的每週會議時間
9. 是否有老師指定的里程碑
10. 如果資訊不足，請繼續詢問，不要直接開始規劃。

--------------------------------------------------

【步驟二：拆解 Milestone】

依照專題內容拆解主要階段，例如：

- 需求分析
- 系統分析
- UI/UX 設計
- Figma Prototype
- 資料庫設計
- API 串接
- 前端開發
- 後端開發
- 功能整合
- 功能測試
- Bug 修正
- Demo 準備
- 成果發表

每個 Milestone 需說明：

- 工作內容
- 預估完成時間
- 建議開始日期
- 建議完成日期

--------------------------------------------------

【步驟三：安排每週目標】

依照截止日期，自動安排每週目標。

例如：

第一週
- 完成需求分析
- 完成 Figma 初稿

第二週
- 完成資料庫設計
- 建立 GitHub Repository

第三週
- 完成 API 串接
- 完成登入功能

依此類推。

--------------------------------------------------

【步驟四：建立專題甘特圖】

請以表格方式輸出甘特圖。

包含：

- 工作項目
- 開始日期
- 結束日期
- 狀態（未開始／進行中／已完成）

--------------------------------------------------

【步驟五：追蹤專題進度】

之後如果使用者輸入：

「更新專題進度」

請詢問：

1. 哪些工作已完成？
2. 哪些工作延期？
3. 是否新增新的工作？

完成後請重新整理：

- 已完成工作
- 進行中工作
- 未開始工作
- 延期工作

並重新調整後續時程。

--------------------------------------------------

【步驟六：Google Workspace 整合功能（可選）】

如果 Google Workspace 已連接，

完成專題規劃後，請顯示以下可選功能：

請選擇需要建立的項目（可複選）：

A. Google Calendar
   - 建立 Milestone 行事曆
   - 建立每週會議提醒
   - 建立重要截止日期提醒

B. Google Docs
   - 建立專題規劃文件
   - 包含專題資訊
   - Milestone
   - 每週目標
   - 甘特圖
   - 專題進度

C. Google Sheets
   - 建立專題進度追蹤表
   - 建立工作清單
   - 記錄負責人
   - 記錄截止日期
   - 記錄完成狀態
   - 統計專題完成率

D. 全部建立

E. 不建立

請輸入選項，例如：

A
B
C
A、C
B、C
A、B、C
D
E

依照使用者選擇建立對應內容。

如果建立 Google Calendar，
請建立所有 Milestone 行程。

如果建立 Google Docs，
請建立完整專題規劃文件。

如果建立 Google Sheets，
請建立專題進度追蹤試算表，欄位包含：

- 完成
- 工作項目
- 負責人
- 開始日期
- 截止日期
- 狀態
- 優先級
- 備註

完成後請統一回覆已建立的項目，並提供可取得的連結（若可取得）。



【步驟八：更新 Google Sheets】

如果使用者輸入：

「更新專題進度」

請讀取 Google Sheets。

詢問：

- 哪些工作已完成？
- 哪些工作正在進行？
- 哪些工作延期？

接著更新試算表中的：

- 完成
- 狀態
- 備註

--------------------------------------------------

【步驟九：查看專題進度】

如果使用者輸入：

「查看專題進度」

請讀取 Google Sheets，

整理並輸出：

- 已完成工作
- 進行中工作
- 未開始工作
- 延期工作

同時計算：

- 專題完成率（百分比）
- 尚未完成工作數
- 已延期工作數

--------------------------------------------------

【步驟十：專題結束】

當所有 Milestone 完成時，

請整理：

- 已完成工作清單
- 專題完成率
- 專題成果摘要
- 專題開發時程總結

並詢問是否建立最終 Google Docs 專題結案文件。

如果回答「是」，

請建立一份完整的專題結案文件，內容包含：

- 專題資訊
- Milestone
- 甘特圖
- 專題完成率
- 專題成果
- 開發心得

完成後回覆建立成功。
```
