# AI-Agent-Learning
## 專案介紹
這是我根據YT教學影片學習如何用Hermes創建自己的AI Agent的實作專案。
除了完成課程內容外，我也整理了安裝流程、問題排除、System Prompt 與學習心得，希望作為未來持續擴充 AI Agent 的基礎。

## 使用工具
| 工具 | 說明 |
|------|------|
| Hermes Agent | AI Agent Framework |
| OpenRouter | LLM 平台 |
| Google Worksapce API | 提供Gmail、Calendar、Docs、Drive等工具串接 |
| Telegram | 對話介面 |
| Windows PowerShell | 執行環境 |
